# 产品需求文档 (PRD) - 数据库结构优化

## 概述

### 项目名称
游戏能力系统数据库结构优化 - AttributeType字段类型转换

### 项目描述
对现有游戏能力系统的数据库结构进行优化，将AttributeValues表中的AttributeType字段从整数类型改为文本类型，使用枚举名称作为值，提高数据的可读性和维护性。这个改动将影响AttributeValues_BasicAttributes和AttributeValues_ShipAttributes两个表。

## 核心功能

### 1. 数据库结构优化
- **字段类型转换**：将AttributeType字段从INTEGER类型改为TEXT类型
- **枚举值映射**：使用GameAbilitySystemEnums.cs中的AttributeType枚举名称作为数据库值
- **数据迁移**：安全地将现有整数值转换为对应的枚举名称
- **向后兼容性**：确保现有代码能够正常工作

### 2. 受影响的表结构
- **AttributeValues_BasicAttributes**：角色基础属性表
  - Health, Energy, Speed, Intelligence, Perception, Charisma, Will, Constitution, Agility
  - LifeValue, MentalValue, MovementSpeed
- **AttributeValues_ShipAttributes**：飞船属性表
  - Thrust, Shield, Armor, Maneuverability, Sensors
  - Mass, Length, Width, Height, CargoCapacity, FuelCapacity

### 3. 数据一致性保证
- **枚举值验证**：确保数据库中的值与枚举定义一致
- **约束检查**：添加CHECK约束验证AttributeType值的有效性
- **索引优化**：重新优化基于AttributeType字段的索引

### 4. 代码适配
- **ORM映射更新**：更新Entity Framework的模型映射
- **查询语句调整**：修改相关的数据库查询代码
- **类型转换处理**：添加枚举与字符串之间的转换逻辑

## 用户体验

### 目标用户
- **主要用户**：游戏开发团队成员
- **次要用户**：数据库管理员和系统维护人员
- **技术水平**：具备数据库和游戏开发经验

### 改进目标
1. **提高可读性**：数据库中的AttributeType值将更加直观易读
2. **简化调试**：开发过程中更容易理解和调试属性相关问题
3. **降低维护成本**：减少因整数枚举值变更导致的数据不一致问题
4. **增强扩展性**：新增属性类型时更加灵活和安全

### 迁移体验
1. **数据备份**：在迁移前自动备份现有数据
2. **渐进式迁移**：分步骤进行数据转换，确保每步都可回滚

### 开发体验改进
- **代码可读性**：查询和操作代码更加直观

## 技术架构

### 数据库结构变更

#### 1. 当前结构分析
```sql
-- 当前AttributeValues表结构
CREATE TABLE AttributeValues (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    AttributeSetId TEXT NOT NULL,
    AttributeType INTEGER NOT NULL,  -- 当前为整数类型
    BaseValue REAL NOT NULL DEFAULT 0.0,
    CurrentValue REAL NOT NULL DEFAULT 0.0,
    MinValue REAL NOT NULL DEFAULT -999999.0,
    MaxValue REAL NOT NULL DEFAULT 999999.0,
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (AttributeSetId) REFERENCES AttributeSets(Id) ON DELETE CASCADE,
    UNIQUE(AttributeSetId, AttributeType)
);
```

#### 2. 目标结构设计
```sql
-- 目标AttributeValues表结构
CREATE TABLE AttributeValues (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    AttributeSetId TEXT NOT NULL,
    AttributeType TEXT NOT NULL,     -- 改为文本类型
    BaseValue REAL NOT NULL DEFAULT 0.0,
    CurrentValue REAL NOT NULL DEFAULT 0.0,
    MinValue REAL NOT NULL DEFAULT -999999.0,
    MaxValue REAL NOT NULL DEFAULT 999999.0,
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (AttributeSetId) REFERENCES AttributeSets(Id) ON DELETE CASCADE,
    UNIQUE(AttributeSetId, AttributeType),
    CHECK (AttributeType IN (
        'Health', 'Energy', 'Speed', 'Intelligence', 'Perception',
        'Charisma', 'Will', 'Constitution', 'Agility', 'LifeValue',
        'MentalValue', 'MovementSpeed', 'Thrust', 'Shield', 'Armor',
        'Maneuverability', 'Sensors', 'Mass', 'Length', 'Width',
        'Height', 'CargoCapacity', 'FuelCapacity', 'CustomAttribute1',
        'CustomAttribute2', 'CustomAttribute3'
    ))
);
```
