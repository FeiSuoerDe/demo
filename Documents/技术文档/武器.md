# 武器系统技术文档

## 1. 概述
武器系统是游戏中的核心战斗机制，通过 `Weapon` 类实现各类武器的功能。该系统支持多种武器类型，具有弹药管理、伤害计算、射击频率控制等功能。

## 2. 武器类型
目前系统支持四种主要武器类型：
- **粒子炮 (ParticleCannon)** - 发射高能粒子束
- **导弹 (Missile)** - 发射追踪或非追踪导弹
- **实弹 (Bullet)** - 发射常规子弹
- **光束 (Beam)** - 发射持续性激光束

## 3. 武器属性

### 3.1 基本属性
| 属性名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| WeaponName | string | "DefaultWeapon" | 武器名称 |
| CurrentWeaponType | WeaponType | ParticleCannon | 当前武器类型 |
| FireRate | float | 1.0f | 武器射速（每秒射击次数） |
| Range | float | 1000.0f | 武器射程（射击距离） |
| TexturePath | string | "res://Textures/Weapons/DefaultWeapon.png" | 武器贴图路径 |

### 3.2 伤害属性
| 属性名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| Damage | int | 10 | 基础伤害值 |
| ShieldDamageMultiplier | float | 0.5f | 对护盾伤害倍率 |
| ArmorDamageMultiplier | float | 1.0f | 对护甲伤害倍率 |
| HealthDamageMultiplier | float | 1.0f | 对生命值伤害倍率 |

### 3.3 弹药相关
| 属性名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| AmmoCapacity | int | 100 | 最大弹药容量 |
| CurrentAmmo | int | 100 | 当前弹药数量 |
| ReloadTime | float | 2.0f | 换弹所需时间（秒） |

## 4. 操作机制

### 4.1 开火机制
- 通过左键点击触发开火
- 支持连续射击（按住左键）
- 射击受 `FireRate` 限制，无法超过设定射速
- 每次射击消耗1单位弹药
- 弹药耗尽时会自动触发换弹

### 4.2 换弹机制
- 按 `R` 键手动触发换弹
- 弹药耗尽时自动触发换弹
- 换弹过程中无法射击
- 换弹时间由 `ReloadTime` 属性决定
- 换弹完成后，弹药恢复至最大容量
