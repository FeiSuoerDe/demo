# 飞船物理体技术文档

本文档详细说明了飞船物理相关的类和组件。

## `SpaceshipPhysics` 类

> 飞船的物理实体，继承自 `RigidBody2D`。负责飞船的基本物理行为和挂载点。

### 属性

| 属性 | 类型 | 描述 | 默认值 |
| :--- | :--- | :--- | :--- |
| `MaxSpeed` | `float` | 飞船的最大速度。 | `200f` |
| `Acceleration` | `float` | 飞船的加速度。 | `100f` |
| `Deceleration` | `float` | 飞船的减速度。 | `50f` |
| `RotationSpeed` | `float` | 飞船的最大旋转速度。 | `500f` |
| `RotationAcceleration` | `float` | 飞船的旋转加速度。 | `200f` |
| `MaxEnergy` | `float` | 飞船的最大辐能值。 | `100f` |
| `EnergyDissipation` | `float` | 飞船能量的常态耗散率。 | `0.1f` |
| `EngineMount` | `Node` | [Export] 用于挂载引擎的节点。 | `null` |
| `WeaponHardpoint` | `Node` | [Export] 用于挂载武器的节点。 | `null` |
| `IsControlled` | `bool` | 标记飞船当前是否被玩家控制。 | `false` |

### 方法

| 方法 | 描述 |
| :--- | :--- |
| `_Ready()` | Godot 引擎在节点准备就绪时调用的方法。用于初始化。 |
| `_PhysicsProcess(double delta)` | 在每个物理帧调用。处理玩家输入（W/S 前进后退，Q/E 旋转），施加力与扭矩，并限制飞船的最大线速度和角速度。 |

---

## `Engine` 类

> 引擎组件，继承自 `Node2D`。定义了飞船引擎的属性。

### 属性

| 属性 | 类型 | 描述 |
| :--- | :--- | :--- |
| `Direction` | `EngineDirection` | 引擎喷口的方向。 |

### `EngineDirection` 枚举

定义了引擎喷口可以朝向的方向。

| 值 | 描述 |
| :--- | :--- |
| `Up` | 向上 |
| `Down` | 向下 |
| `Left` | 向左 |
| `Right` | 向右 |

---

## `WeaponHardpoint` 类

> 武器挂载点，继承自 `Node2D`。定义了武器槽位的属性。

### 属性

| 属性 | 类型 | 描述 |
| :--- | :--- | :--- |
| `Type` | `WeaponType` | 槽位可以安装的武器类型。 |
| `Size` | `HardpointSize` | 槽位的大小规格。 |

### `WeaponType` 枚举

定义了武器的类型。

| 值 | 描述 |
| :--- | :--- |
| `Energy` | 能量武器 |
| `Missile` | 导弹武器 |
| `Kinetic` | 动能武器 |

### `HardpointSize` 枚举

定义了武器槽位的大小。

| 值 | 描述 |
| :--- | :--- |
| `Small` | 小型槽位 |
| `Medium` | 中型槽位 |
| `Large` | 大型槽位 |
| `ExtraLarge` | 特大型槽位 |
