# 飞船物理体技术文档

本文档详细说明了飞船物理相关的类和组件。

## `SpaceshipPhysics` 类

> 飞船的物理实体，继承自 `RigidBody2D`。负责飞船的基本物理行为和挂载点。

### 枚举

#### `ShipState` 枚举

定义了飞船的状态。

| 值 | 描述 |
| :--- | :--- |
| `Idle` | 待机状态 |
| `Off` | 熄灭状态 |
| `On` | 开启状态 |
| `Boosting` | 加速状态 |

### 常量

| 常量 | 类型 | 描述 | 值 |
| :--- | :--- | :--- | :--- |
| `BOOST_SPEED_MULTIPLIER` | `float` | 加速状态下速度提升倍率 | `2.0f` |
| `BOOST_TURNING_MULTIPLIER` | `float` | 加速状态下转向速度提升倍率 | `2.0f` |
| `STRAFE_FORCE_RATIO` | `float` | 平移力相对于前进力的比率 | `0.5f` |
| `TURNING_FORCE_MULTIPLIER` | `float` | 转向力乘数 | `10f` |
| `ROTATION_DAMPING` | `float` | 旋转阻尼系数 | `2f` |
| `MIN_ANGULAR_VELOCITY` | `float` | 最小角速度阈值 | `0.1f` |

### 属性

| 属性 | 类型 | 描述 | 默认值 |
| :--- | :--- | :--- | :--- |
| `MaxSpeed` | `float` | 飞船的最大速度。 | `200f` |
| `Acceleration` | `float` | 飞船的加速度。 | `100f` |
| `Deceleration` | `float` | 飞船的减速度。 | `50f` |
| `RotationSpeed` | `float` | 飞船的最大旋转速度。 | `500f` |
| `RotationAcceleration` | `float` | 飞船的旋转加速度。 | `200f` |
| `MaxEnergy` | `float` | 飞船的最大辐能值。 | `100f` |
| `EnergyDissipation` | `float` | 飞船能量的常态耗散率。 | `0.1f` |
| `currentState` | `ShipState` | 当前飞船状态 | `ShipState.Idle` |
| `isBoosting` | `bool` | 是否处于加速状态 | `false` |
| `isMoving` | `bool` | 是否处于移动状态 | `false` |
| `ShipData` | `ShipData` | [Export] 飞船数据 | - |
| `Weapons` | `List<Weapon>` | 飞船武器列表 | 空列表 |
| `Engines` | `List<Engine>` | 飞船引擎列表 | 空列表 |
| `SpeedLabel` | `Label` | [Export] 显示速度的标签 | `null` |
| `AngularSpeedLabel` | `Label` | [Export] 显示角速度的标签 | `null` |
| `AngleLabel` | `Label` | [Export] 显示角度的标签 | `null` |
| `WeaponStatusLabel` | `Label` | [Export] 显示武器状态的标签 | `null` |
| `EngineMount` | `Node` | [Export] 引擎槽位节点 | `null` |
| `WeaponHardpoint` | `Node` | [Export] 武器槽位节点 | `null` |
| `IsControlled` | `bool` | 标记飞船当前是否被玩家控制 | `false` |

### 方法

| 方法 | 描述 |
| :--- | :--- |
| `_Ready()` | Godot引擎在节点准备就绪时调用的方法。初始化飞船，确保引擎初始状态正确，获取所有武器和引擎。 |
| `_PhysicsProcess(double delta)` | 在每个物理帧调用。处理移动输入、转向输入，更新飞船状态，应用物理力和扭矩，限制最大速度和角速度，更新UI。 |
| `ResetStateForPhysicsUpdate()` | 重置物理更新的状态，更新当前速度。 |
| `HandleMovementInput()` | 处理移动输入并返回要应用的力。处理前进(W键)、后退(S键)、左平移(A键)和右平移(D键)。 |
| `HandleRotationInput()` | 处理转向输入并返回要应用的扭矩。判断是使用手动转向还是鼠标指向转向。 |
| `HandleManualRotation()` | 处理手动旋转(Shift+Q/E)，包括旋转阻尼。 |
| `HandleMouseRotation()` | 处理鼠标方向旋转，自动计算所需扭矩以面向鼠标位置。 |
| `UpdateShipState()` | 根据当前移动和加速状态更新飞船状态。 |
| `LimitMaxSpeed()` | 限制飞船的最大线速度。 |
| `LimitMaxAngularVelocity()` | 限制飞船的最大角速度。 |
| `UpdateUI()` | 更新所有UI显示。 |
| `UpdateSpeedLabel()` | 更新速度标签，显示当前速度和加速状态。 |
| `UpdateAngleLabel()` | 更新角度标签，显示当前旋转角度。 |
| `GetWeapons()` | 获取所有挂载的武器，返回武器列表。 |
| `GetWeaponFromNode()` | 从节点获取武器组件，支持检查子节点。 |
| `GetEngines()` | 获取所有挂载的引擎，返回引擎列表。 |
| `UpdateWeaponStatus()` | 更新武器状态显示，包括名称、状态和弹药信息。 |
| `UpdateAngularSpeed()` | 更新角速度显示。 |
| `SetShipState(ShipState state)` | 设置飞船状态，如果状态改变则更新引擎。 |
| `UpdateEngines()` | 更新所有引擎的状态，使其与飞船状态一致。 |

## `Engine` 类

> 引擎组件，继承自 `Node2D`。定义了飞船引擎的属性。

### 枚举

#### `EngineState` 枚举

定义了引擎的状态，与飞船状态对应。

| 值 | 描述 |
| :--- | :--- |
| `Idle` | 待机状态 |
| `Off` | 熄灭状态 |
| `On` | 开启状态 |
| `Boosting` | 加速状态 |

### 属性

| 属性 | 类型 | 描述 |
| :--- | :--- | :--- |
| `Direction` | `EngineDirection` | 引擎喷口的方向。 |

### 方法

| 方法 | 描述 |
| :--- | :--- |
| `SetEngineState(EngineState state)` | 设置引擎的状态 |

### `EngineDirection` 枚举

定义了引擎喷口可以朝向的方向。

| 值 | 描述 |
| :--- | :--- |
| `Up` | 向上 |
| `Down` | 向下 |
| `Left` | 向左 |
| `Right` | 向右 |

## `WeaponHardpoint` 类

> 武器挂载点，继承自 `Node2D`。定义了武器槽位的属性。

### 属性

| 属性 | 类型 | 描述 |
| :--- | :--- | :--- |
| `Type` | `WeaponType` | 槽位可以安装的武器类型 |
| `Size` | `HardpointSize` | 槽位的大小规格 |

### `WeaponType` 枚举

定义了武器的类型。

| 值 | 描述 |
| :--- | :--- |
| `Energy` | 能量武器 |
| `Missile` | 导弹武器 |
| `Kinetic` | 动能武器 |

### `HardpointSize` 枚举

定义了武器槽位的大小。

| 值 | 描述 |
| :--- | :--- |
| `Small` | 小型槽位 |
| `Medium` | 中型槽位 |
| `Large` | 大型槽位 |
| `ExtraLarge` | 特大型槽位 |

## 操作手册

> **警告**: 本操作手册仅供授权飞行员使用。未经训练人员不得操作本型号飞船。

### 1. 飞行前检查

#### 1.1 系统自检
- 确认动力子系统状态: `动力子系统上线`
- 确认引擎子系统状态: `引擎子系统上线`
- 确认指挥权限: `指挥权限已移交`

#### 1.2 武器系统检查
- 查看武器挂载状态: 所有武器应在`WeaponStatusLabel`中显示
- 确认武器供能情况: 能量型武器需要检查充能状态
- 确认弹药储备: 动能武器和导弹武器需要确认弹药充足

### 2. 基本飞行操作

#### 2.1 推进控制
| 控制指令 | 按键 | 操作效果 |
|:---------|:-----|:--------|
| 前向推进 | W | 飞船向前方加速 |
| 后向推进 | S | 飞船向后方加速 |
| 左侧平移 | A | 飞船向左侧平移 |
| 右侧平移 | D | 飞船向右侧平移 |

**注意**: 平移推进力为前进力的50%

#### 2.2 转向控制
| 控制模式 | 按键组合 | 操作效果 |
|:---------|:---------|:--------|
| 标准模式 | 鼠标指向 | 飞船自动转向面对鼠标位置 |
| 手动模式 | Shift+Q | 飞船向左旋转 |
| 手动模式 | Shift+E | 飞船向右旋转 |

**注意**: 当不施加转向力时，飞船会自动应用旋转阻尼减速

### 3. 高级操作

#### 3.1 精确定位
1. 使用平移控制(A/D)与前后推进(W/S)组合
2. 手动转向模式(Shift+Q/E)可实现精确角度调整
3. 观察角度指示器(AngleLabel)获取当前朝向信息

#### 3.2 速度管理
1. 速度标签(SpeedLabel)显示当前速度及其相对最大速度的百分比
2. 系统会自动限制线速度和角速度，防止失控
3. 角速度标签(AngularSpeedLabel)显示当前旋转速率

### 4. 武器系统操作

#### 4.1 武器状态监控
- 武器状态面板(WeaponStatusLabel)显示所有武器的当前状态
- 检查每种武器的冷却时间和弹药状态

#### 4.2 武器组控制
- 根据挂载在WeaponHardpoint上的武器进行相应操作
- 不同类型武器(能量/动能/导弹)有各自的操作特性和限制

### 5. 引擎管理

#### 5.1 引擎状态
| 状态 | 描述 | 表现 |
|:-----|:-----|:-----|
| Idle | 待机状态 | 引擎保持低功率运行，无明显推力 |
| Off | 熄灭状态 | 引擎完全关闭，不产生推力 |
| On | 开启状态 | 引擎正常工作，产生标准推力 |
| Boosting | 加速状态 | 引擎最大功率，提供额外推力 |

#### 5.2 引擎响应
- 引擎状态会根据飞行输入自动切换
- 移动时引擎自动从Idle切换到On状态
- 停止输入后引擎返回Idle状态

### 6. 紧急程序

#### 6.1 速度过载处理
1. 立即停止所有推进输入
2. 应用反向推力减速至安全速度
3. 监视速度指示器，确保在安全范围内

#### 6.2 角速度失控
1. 停止所有旋转输入
2. 系统将自动应用旋转阻尼
3. 待角速度降至安全值后恢复正常操作

---

**注**: 本操作手册符合宇宙船舶操作标准程序(SOP-XC-42)，由星际飞行员协会认证。
